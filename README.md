# PhishAware

PhishAware is a beginner cybersecurity awareness website designed to help users understand phishing attacks and recognize suspicious online messages.

## Project Goal

The goal of this project is to educate users about phishing and encourage safer online behavior.

## Features

- Welcome and About sections.
- Security Tips.
- Common Phishing Signs.
- Phishing Examples.
- Interactive Quiz with 10 questions.
- Quiz score and percentage results.
- Previous and Next question navigation.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

How to Run

1. Install Python from https://www.python.org/downloads/
2. Download or clone this repository.
3. Open the project folder in VS Code or Terminal.
4. Install Flask:pip install flask

pip install flask

5. Run the application:
6. python app.py

python app.py

6. Open your browser and visit:
    http://127.0.0.1:5000
