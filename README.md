# PhishAware

PhishAware is a beginner cybersecurity awareness website designed to help users understand phishing attacks and recognize suspicious online messages.

## Project Goal

The goal of this project is to educate users about phishing and encourage safer online behavior.

## Features

- Welcome and About sections.
- Security Tips.
- Common Phishing Signs.
- Phishing Examples.
- Interactive Quiz with 10 questions.
- Quiz score and percentage results.
- Previous and Next question navigation.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run

1. Install Python.
2. Install Flask:

   pip install flask

3. Run the application:

   python app.py

4. Open your browser and visit:

   http://127.0.0.1:5000
